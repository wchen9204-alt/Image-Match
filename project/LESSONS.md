# 项目复盘记录

- 直接法没有输出真实离散对应点时，不能复用点特征法的 `num_inliers` 语义。直接法验证需要拆开：  
  - 对真实输出点对和内点 mask 的方法，使用点对质量检查。  
  - 对 ECC、相位相关、Fourier-Mellin 等方法，使用直接法专属 confidence 检查。
- Edge IoU 只能作为 direct/warp 的补充诊断指标。直接法出现“覆盖上但没对齐”的误判时，应设计通用的内容一致性判定，不能只为单个用例收紧全局阈值。
- 直接法借用点特征法结果时，应把点特征结果定位为“初始值候选”并单独做安全门校验；不能把点特征候选通过等同于直接法最终配准成功。
- 直接法最终 warp 若只因为 photometric 阈值失败，但点特征初始值已经按自身规则被接受，且直接法结果没有比该初值更差，同时 overlap / coverage / edge / 点分布仍然强通过，则应允许它作为直接法最终成功的补充判定，避免把“初值已确认正确、细配准只是没把 NMAD 压得更低”的样本误杀。
- 直接法借用点特征初始值时，最终成功判定策略不要硬编码成单一特判；应通过 YAML 提供显式策略开关，例如“只看 direct 最终结果”或“direct 失败时允许回看已接受 initializer”，避免不同实验阶段反复改代码切换口径。
- 对可选输出文件，例如 direct initializer 的 false-color overlay，本轮不再生成时必须先清理旧文件，避免把历史输出误认为当前结果。
