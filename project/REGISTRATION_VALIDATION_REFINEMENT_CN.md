# 配准结果判定指标优化记录

## AKAZE 样本观察

以下结论以 `percentile: 90`、`max_abs_error: 0.10` 为当前观察基线。样本编号均来自 AKAZE 批处理结果。

误判为错误：
1.重合部分大面积灰度不一致：test07、test20、test64

2.局部噪声干扰或部分线条缺失，90分位较高但75分位很低：test28、test31、test95、test98、test130

误判为正确：
1.有局部未重合，但重合部分高度差较小：test09、test29、test30

2.大范围重合但角度错位，由于大面积重复纹理等导致90分位值很小：test04、test14

## 当前结论

高度差 P90 能有效描述“绝大多数有效重叠像素”的差异，并且比只使用平均值更容易暴露局部大偏差。但它不能单独证明配准正确：

1. P90 只看有效重叠区域，不能代替包含率或有效重叠比例。
2. 重复纹理与大面积相似背景可能使错误变换获得较低 P90。
3. 灰度差会同时受到几何错位、光照变化、纹理变化、噪声和线条栅格化影响。

### 当前使用的高度差判定

在 warp 后 source 与 target 的共同有效前景区域内，将灰度归一化到 `[0, 1]`，计算逐像素绝对差。当前 AKAZE 配置的判定顺序如下：

1. 原始绝对差 P90 不超过 `0.15`，通过。
2. 原始 P90 超过阈值时，若原始 P75 不超过 `0.15`，且较小前景被另一图包含的比例不低于 `0.90`，按局部噪声例外通过。
3. 仍未通过时，计算共同有效前景内有符号灰度差的 90% 截尾均值作为全局高度偏移，补偿 source 后重新计算 P90；补偿后 P90 不超过 `0.15`，通过。
4. 以上条件均不满足，则高度差判定失败。

仅依赖灰度差难以区分真实配准与大面积重复纹理造成的表面相似，因此引入线组，以结构一致性作为判定依据，避免重复纹理干扰判定。

### 面向结构简单长条图的尝试

通用结构指标误判较多，因此尝试将线段结构判定用于边界清晰、结构简单的长条图。
这类图像的外轮廓和分隔线位置相对稳定，可作为灰度差之外的配准证据。
后续再验证其适用范围、线组提取方式和最终判定规则。

#### 初版大致流程

```text

  ↓

  ↓

  ↓

  ↓
分别比较双方水平组、竖直组的方向、位置和实际支撑区间
  ↓
水平组和竖直组都具有匹配证据则 PASS；任一方向存在明确结构冲突则 FAIL；
任一方向证据不足则 INSUFFICIENT
```

#### 存在的问题与解决方案

(1) LOCAL 模式的问题
采用 area_ratio < 0.75 进入LOCAL 模式并直接使用较小图的前景范围作为`comparison_domain_mask`可能导致：
1. 仅根据 area_ratio < 0.75 进入 LOCAL 不可靠，例如test04，将使用全景模式的图误用为局部模式。
2. 大图位于小图范围之外的长线、转折和冲突结构在提取线组前已被删除，大图结构证据已被裁剪，无法正确判断大图自身的主方向等信息。例如test29

解决方案：
1.不再采用全 景 or 局部的模式，双方始终在各自完整前景提取边缘等信息。
2.峰高差不作为候选的硬筛选条件，但峰位置差仍是候选匹配的主要条件；只有位置相近的有效峰才进入候选池。

（2）长条形图像初始过滤仅使用长宽比，放入部分非长条形图像
解决方案：
1. source 或 target 任一侧前景的长宽比不低于 `min_foreground_elongation_ratio`。
2. 实现中先从二值前景取得全部前景像素，求其凸包并填充为实心区域；再由该区域的几何矩计算
   重心、横纵坐标方差及协方差，并直接求出主轴角度：
   `angle = 0.5 * atan2(2 * covarianceXY, covarianceX - covarianceY)`。
   该角度对应像素相对重心变化最大的方向，即 PCA 主轴。沿主轴从一端到另一端每 `2 px` 切成
   一段，段内只要有前景像素就记为占用；占用段数除以总段数即为区间占用率，要求不低于
   `min_axis_occupancy`，以排除沿主轴存在大段空缺的形状。
3. 沿该延伸方向观察前景的多个横截面，要求各截面的中心大多接近同一条中心线；
   中心偏差的 P90 不高于 `max_centerline_deviation_ratio`，用于排除整体明显弯折、呈 S 形，
   或一侧存在大凸起而使截面中心持续偏移的形状。
结果：只有test88会被误判通过

（3）存在较短线段的干扰
初始过滤方式：
只过滤长度小于 `min_fragment_length_pixels`（当前 6px）的原始短片段。

解决方法：增加相对长度过滤。线组完成拟合、基本质量过滤并分类为水平或竖直后，其真实边缘长度需达到同图、同方向最长候选线组真实边缘长度的一定比例（当前0.5），才进入后续匹配证据。

（4）最终得到线段过多、并且有很多是断裂的线段
原因：
1.图中白色粗线通常由两侧边界，提取边缘会得到”两侧边缘“，并且两侧边缘又分别形成一条白线，最后在直线检测时检测到四条线段，例如test03
2.局部情况，较小图的两边也可能产生边，例如test32、125
解决方案：
1.不再提取边缘，也就不用考虑边缘过滤阈值，直接使用直线检测器
a.直线检测器检测出的断裂的短线段较多，还可能因为边缘的微小突变检测对一条边缘检测出三条线：关于两侧边缘，水平线只保留最外侧的边缘，竖直线保留右侧边缘
2.不再按固定的左右边界距离删除竖直线，避免把真实端部竖边一并删除；由后续线组匹配和支撑证据判断其是否有效。

（5）线组对匹配与方向证据判定不合理
旧方法：
一对 source/target 线组只有同时满足以下条件才算严格通过：
1. 法向位置差 <= `final_position_tolerance_pixels`；
2. 实际支撑区间重叠长度 >= `min_line_pair_overlap_pixels`；
3. 实际重叠长度 / 较短线实际长度 >= `min_shorter_line_overlap_ratio`；
4. 线组角度差 <= `max_line_pair_angle_difference_degrees`。

水平、竖直方向分别计算 source、target 的严格匹配率：
```text
严格匹配率 = 参与严格通过线对的该侧线组数 / 该侧有效线组总数
```
初始规则要求 source、target 至少一侧严格匹配率达到当时配置的最低比例`min_line_group_match_ratio`，
且双方严格匹配的真实边缘总长度中较小者达到 `min_direction_matched_length_pixels`，
该方向才算通过；水平、竖直两个方向都通过才得到最终通过。

解决方案：
水平主方向线对的严格验证：
1. 拟合线组角度差不超过 `max_line_pair_angle_difference_degrees`。
2. 先从候选线对的法向位置差中取中位数作为双方共同法向偏移，再检查每个线对扣除该偏移后的
   法向残差不超过 `final_position_tolerance_pixels`。因此检查的是各线对之间是否
   存在相对错位，而非要求共同法向偏移必须为零。
3. 两条拟合线在切向方向的重叠长度除以较短拟合线跨度，不低于
   `min_shorter_line_overlap_ratio`（当前 `0.90`）。

竖直辅助线对只要求存在切向重叠的候选，并检查扣除共同法向偏移后的法向残差；不以角度差或切向重叠率作为严格拒绝条件。
真实断裂片段仍用于分组、线组质量过滤、长度和断裂诊断；最终严格几何匹配使用拟合线的角度、法向残差和切向区间，而不直接要求真实片段重叠。

方向证据汇总：水平方向以可靠主线对为主要证据；竖直方向至少存在一对基本法向位置证据，且不能出现多对候选线组均明显法向错位的系统性冲突。

（6）拟合后断裂片段仍可能因局部错位被拆分为多个线组，例 test49
解决方法：
在过滤内侧长边和竖直方向左侧边、只保留最终有效线组之后，对保留的水平主方向线组和竖直辅助线组都进行一次较宽松的二次分配。二次分配要求线组方向一致、拟合线的切向区间不重叠、法向距离在 `post_fit_group_normal_distance_pixels` 范围内。合并后重新拟合，并用拟合残差、方向离散和实际支撑长度进行复核。

（7）最终线组证据状态混淆，导致明确不匹配被判为 `INSUFFICIENT`
初始做法：
旧实现先分别计算水平、竖直方向的候选线组对和严格匹配结果：水平只有较少一侧线组全部严格通过且歧义比例不超过阈值才判 `PASS`，竖直只要有一对基本法向位置匹配即可判 `PASS`；其余情况先判 `INSUFFICIENT`，只有满足双方线组数量不少于 3 组、强冲突比例达到阈值、未匹配长度比例达到阈值，或较长一侧证据长度至少为较短一侧 3 倍等附加门槛时才升级为 `FAIL`。
这些规则把“无法比较”“比较后不匹配”和“部分证据”混成了同一种状态。

解决方案：
优化后的状态判定规则：
1. `INSUFFICIENT` 只表示无法可靠比较：主方向不可靠，或该方向 source/target 至少一侧没有最终有效线组。
2. 双方都有有效线组后，即视为已经具备可比较证据。候选线组对为 0，或候选线组对全部未通过严格验证，判为 `FAIL`。
3. 水平方向不再要求较少一侧所有线组都通过；存在一对可靠主方向线对即可通过。剩余线段的缺失、断裂、局部拟合偏差和歧义仅输出诊断信息，不能否定已有匹配，因此 `test31、test42、test47` 不应因额外或缺失线段而被拦截。
4. 竖直方向至少需要一对可靠的法向位置证据；若双方都有竖直线组但候选线组对为 0，判为 `FAIL`。若已有匹配线对，但 source 和 target 两侧的未解释支撑比例均超过 `max_vertical_unmatched_length_ratio`（当前为 `0.70`），则判为 `INSUFFICIENT`，继续交由高度差等后续指标判断。
5. 删除按线组数量、通过比例、强冲突比例、歧义比例和三倍长度特例进行状态升级的旧规则；未匹配长度统计仅用于诊断，以及识别竖直方向证据是否不足，不作为一般性的通过比例门槛。

（8）分组逻辑修正
旧实现：
片段先按长度从长到短处理，以线组中的最长片段作为固定锚点；每个后续片段依次尝试加入已有线组，只与锚点比较方向和法向距离，全部不满足时才新建线组。锚点不会根据已加入片段重新调整，且分组时不检查组内片段之间的整体关系和切向区间，导致局部偏移的同一条断裂边可能被拆组，切向重叠的不同边也可能被误合并，最终造成拟合线缺失或错误。

解决方案：
1. 按共同参考方向先将片段分为水平和竖直两类，并按切向位置处理，不再以片段长度或检测顺序作为归组依据。
2. 新片段加入候选线组前，必须与该组内全部已有片段同时满足：方向一致、法向位置一致、切向区间不重叠。
3. 归组完成后，保留组内全部真实断裂片段，再统一拟合一条逻辑直线；长度、断裂间隙、连续性和拟合残差只用于线组质量统计与后续过滤。
