# 源码文件说明目录

这个目录用于集中存放针对具体 `.h` / `.cpp` 文件的中文说明文档。

当前约定：

- 一个源码模块对应一份或多份说明文档
- 说明内容以“当前真实代码”为准
- 优先记录：
  - 文件职责
  - 重要类/结构体
  - 关键函数流程
  - 调用关系
  - 相对旧版本的修正点
