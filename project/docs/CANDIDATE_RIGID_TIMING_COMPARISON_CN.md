# 第二阶段：初步优化

1. `pairwise_rigid_consistency` 过滤。
2. 基于 `filtered_matches` 的额外 rigid 候选：先按描述子距离取最多 `64` 条匹配作为候选池，再混合选择最多 `24` 个 seed 生成候选模型并统一比较。
3. 自定义严格刚体 RANSAC：以过滤后的对应点集为输入，沿用项目原有的固定种子随机采样实现，每次随机抽取两对点估计旋转和平移矩阵；按重投影误差统计内点，迭代 `1000` 次后保留内点数最多的模型，并使用最佳内点重新拟合最终刚体矩阵。
