# 第三阶段：结构判定优化（进行中）

## 当前目标

1. 基础有效性：矩阵存在且满足最小内点数。
2. 双向结构边缘匹配：取 warped source 到 target 与反向命中率的较小值。
3. 有效视场覆盖率：限制评估范围，避免 warp 边界和无效区域干扰。
4. 候选唯一性：输出最高、第二高候选的结构分数差，暂不作为 AKAZE 硬门槛。
