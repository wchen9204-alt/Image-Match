# 按灰度值多层提取特征配准

## 初始方案

如果一阶段配准失败，则进入二阶段配准-多层特征配准：多层特征提取，放大灰度差。
1. 多层关键点提取：循环10次，每次将灰度值大于该层的区域置为0，然后提取关键点和描述子，将10次的结果合并，合并过程中去除KeyPoint相同的关键点。
2. 描述子重计算：在原图上使用多层特征提取的关键点重新计算描述子
3. 描述子匹配：使用BFMatcher进行描述子匹配，knn的k设置为64
4. 匹配点对过滤：每个关键点对应的match列表，以match[0].distance作为best_distance，将该关键点的匹配对象中distance < 2 * best_distance的匹配点对作为候选匹配
5. 匹配点对投票：遍历所有匹配点对，将每个点对的配准仿射变换按angle, tx, ty分bin，旋转角5度为一个bin，tx和ty为10一个bin，得到若干个匹配点簇
6. 匹配点簇过滤：按匹配点簇大小保留top-10匹配点簇
7. 几何验证：对每个匹配点簇执行RANSAC配准验证，内点不低于6个时接受结果
8. 结果排序：对多个点簇可能生成的多个被接受的结果，按source重叠率、target重叠率、重叠有效区域灰度残差P90综合打分，取最高者作为结果

### 1. 多层关键点提取

对 source 和 target 分别执行多层关键点提取。默认循环 10 次，每次生成一个暗部图层。

设总层数为 `L`，第 `i` 层的灰度阈值为：

```text
threshold(i) = floor(255 * (L - i) / L)
```

当 `L = 10` 时，阈值依次为：

```text
255, 229, 204, 178, 153, 127, 102, 76, 51, 25
```

每一层的处理过程如下：

1. 读取原始灰度图。
2. 将灰度值大于当前层阈值的区域置为 0。
3. 保留灰度值小于等于阈值的区域作为当前暗部图层。
4. 将当前暗部图层的有效灰度范围归一化并拉伸到 `0..255`，使暗部细节具有适合特征提取的对比度。
5. 在归一化后的暗部图层上检测关键点并生成该层的描述子。
6. 保存该层检测到的关键点，进入下一层。

多层提取阶段只负责发现关键点。每一层生成的描述子不直接用于最终匹配，后续会统一在原图上重新计算描述子。

#### 关键点合并和去重

10 层处理完成后，将所有层的关键点合并为一个关键点集合。合并时判断两个 `KeyPoint` 是否相同，但不比较描述子内容是否相同。

关键点相同性至少应比较以下属性：

- 位置：`pt.x`、`pt.y`
- 尺寸：`size`
- 方向：`angle`
- 必要时可继续比较 `octave`、`class_id` 等 OpenCV 关键点属性

如果两个关键点的这些属性相同，则只保留一个关键点；如果关键点位置相同但尺寸或方向不同，则按照不同关键点保留。去重的目的只是避免同一层结构在多个阈值下重复进入匹配，不是按照描述子距离删除候选。

如果某一层没有有效暗部像素，或者 AKAZE 在该层没有检测到关键点，则跳过该层，继续处理剩余层，不应使整张图的多层提取失败。

### 2. 描述子重计算

多层关键点合并完成后，在 source 和 target 的原始灰度图上分别重新计算描述子：

1. 使用合并后的 source 关键点和原始 source 灰度图计算 source 描述子。
2. 使用合并后的 target 关键点和原始 target 灰度图计算 target 描述子。
3. 删除无法成功计算描述子的关键点，确保关键点数量与描述子行数一致。

这样设计有两个作用：

- 多层暗部图像只负责让暗部结构更容易被 AKAZE 检测出来。
- 描述子仍然从原图局部纹理计算，避免归一化后的暗部图层改变描述子本身的灰度关系。

最终输出的关键点和描述子必须保持一一对应：描述子第 `n` 行对应关键点数组中的第 `n` 个关键点。

### 3. 描述子匹配

使用 OpenCV `BFMatcher` 对 source 描述子和 target 描述子执行 KNN 匹配：

```cpp
BFMatcher matcher(normType);
matcher.knnMatch(source_descriptors,
                 target_descriptors,
                 knn_matches,
                 64);
```

其中 `k = 64`，即每个 source 关键点最多返回 64 个 target 候选匹配。距离范数应与 AKAZE 描述子类型匹配：

- 二进制描述子使用 Hamming 范数。
- 浮点描述子使用 L2 范数。

KNN 结果按 source 关键点分组保存。每组候选的第一个元素是距离最小的候选，用作后续扩展过滤的基准。

### 4. 匹配点对过滤

对于每个 source 关键点对应的 KNN 匹配列表：

1. 如果该列表为空，则跳过。
2. 读取 `match[0].distance`，记为 `best_distance`。
3. 遍历该列表中的候选匹配。
4. 将满足以下条件的点对加入候选集合：

```text
match.distance < 2 * best_distance
```

这里的 `best_distance` 是当前 source 关键点自己的最佳距离，不是全部匹配的全局最小距离。因此，每个 source 关键点都有独立的候选距离范围。

该步骤不是传统的 Lowe 比率测试：它不比较 `match[0]` 和 `match[1]` 的距离，而是保留最佳距离两倍以内的多个候选，用于后续刚体投票。这样可以在暗部描述子相似度不稳定时保留更多潜在正确对应关系。

过滤后的候选匹配应至少记录：

- source 关键点索引 `queryIdx`
- target 关键点索引 `trainIdx`
- 描述子距离 `distance`

### 5. 匹配点对投票

遍历所有过滤后的匹配点对，为每个点对计算一个隐含的刚体变换参数。

设 source 关键点为 `(x_s, y_s)`，target 关键点为 `(x_t, y_t)`，source 和 target 关键点方向分别为 `a_s`、`a_t`，则：

```text
angle = a_t - a_s
```

根据该旋转角计算 source 点旋转后的坐标，再得到平移量：

```text
tx = x_t - (cos(angle) * x_s - sin(angle) * y_s)
ty = y_t - (sin(angle) * x_s + cos(angle) * y_s)
```

对 `(angle, tx, ty)` 分别进行分桶：

- 旋转角每 5 度为一个 bin。
- `tx` 每 10 像素为一个 bin。
- `ty` 每 10 像素为一个 bin。

将三项均落入相同 bin 的匹配点对放入同一个字典条目，字典的键为：

```text
(angle_bin, tx_bin, ty_bin)
```

最终每个字典条目就是一个匹配点簇。点簇越大，表示越多匹配点支持相近的旋转和平移假设。

关键点方向无效时，应使用统一的默认方向（例如 0 度），保证投票过程不会因为无效角度产生未定义结果。

### 6. 匹配点簇过滤

按照每个匹配点簇包含的匹配数量从大到小排序，只保留前 5 个点簇：

```text
clusters = sort_by_size_descending(all_clusters)
clusters = clusters[0 : min(5, clusters.size())]
```

点簇数量不足 5 个时全部保留。小点簇通常只得到少量支持，直接过滤可以减少错误模型估计和后续 RANSAC 的计算量。

保留点簇时应保留原始 `DMatch` 索引，不能只保存坐标副本，否则后续无法将最佳模型的内点 mask 写回通用匹配数据，也无法正确绘制内点匹配图。

### 7. 几何验证

对每个保留的匹配点簇独立执行严格刚体 RANSAC：

1. 从当前点簇中准备 source / target 坐标对。
2. 每轮随机抽取两对点。
3. 使用两对点估计旋转和平移，不允许缩放、剪切或透视变形。
4. 将模型应用到点簇内所有 source 点。
5. 计算预测点与 target 点之间的重投影误差。
6. 重投影误差不超过 5 像素时，将该点对计为内点。
7. 完成 1000 次迭代后，保留内点数量最多的模型。
8. 使用最佳模型的全部内点重新拟合一次严格刚体矩阵。

RANSAC 参数：

```text
最小内点数：6
重投影阈值：5 px
最大迭代次数：1000
```

当最佳模型的内点数小于 6 个时，当前点簇不接受，继续验证下一个点簇。内点 mask 必须与当前点簇中的匹配顺序一致，并在最终选择后写回运行上下文。

### 8. 结果排序

多个匹配点簇可能分别产生有效刚体结果。对所有通过几何验证的候选结果进行统一排序，选择综合质量分数最高的结果作为第二阶段最终结果。

评分使用 source、target 和重合区域三部分信息：

```text
score = 0.4 * source_overlap
      + 0.4 * target_overlap
      + 0.2 * (1 - local_gray_residual_p90 / 255)
```

其中：

- `source_overlap`：Warp 后 source 前景落在 target 有效区域内的比例。
- `target_overlap`：Warp 后 source 前景与 target 前景的重合比例。
- `local_gray_residual_p90`：对有效重合区域内每个 Warp 后的 source 像素，在 target 对应位置半径 `2 px` 的圆形邻域内，仅从非零前景像素中寻找最小灰度绝对差，再统计这些局部最小差值的 90 分位值。

评分前应排除无效矩阵、空前景或无有效重合区域的候选。若多个候选分数相同，可优先选择内点数更多、平均重投影误差更小的候选。

当前错误用例：test01，04，05、07，12，14，19，22，37，41，43，52，92
错误原因：
1. 内点聚集于统一区域或同一条直线，导致整体有角度或位移偏差，例如test01、07、52、92
2. 相似边缘、纹理产生的关键点相互匹配错误，例如test04、05、12、14、22、37、41、43


1. warped source 前景像素到 target 前景的最近距离 `<= 2 px` 时计为 source 重叠。
2. target 前景像素到 warped source 前景的最近距离 `<= 2 px` 时计为 target 重叠。
3. 分别计算 source、target 重叠比例后再进入总分。

## 使用点对角度差投票

从 source/target 的候选关键点中枚举点对，计算两条连线相对水平方向的角度差，代替关键点自身方向角度差。

1. 关键点过滤：使用 response > 0.008，50*50px的网格只保留响应值最高的10个关键点过滤，减少关键点数量和后续点对计算量。
2. 建立有序点对距离索引：分别为 source、target 中的关键点构建有序点对距离索引，选择的点对之间的距离至少为前景包围盒宽度的一半。
3. 根据点对距离寻找候选匹配：选择两图关键点数量较少的一个，在另一张图的点对中找距离差不超过3px作为匹配，最多64个
4. 计算角度差和位移：计算一对关键点与它最多64个匹配的角度差和选择后的位移
5. 根据角度和位移投票分簇：旋转角5度为一个bin，tx和ty为10一个bin，具有相同 (angle_bin, tx_bin, ty_bin) 的点对投票进入同一簇。

### 1. 多层特征与匹配

- 关键点响应值过滤：仅保留 `response > 0.008` 的关键点。
- 空间网格过滤：每个 `50 px` 网格最多保留响应值最高的 `10` 个关键点。
- 两种模式都使用 KNN（`k = 64`）描述子匹配，并以每个源关键点的最佳匹配距离 `d0` 为基准，保留满足 `distance < 2 * d0` 的扩展匹配；区别仅在于投票参数来自关键点自身方向还是关键点连线。
 
### 2. 最小点对距离与距离索引
 
1. 对 source、target 分别取非零前景中的最大连通域，并得到其包围盒。
2. 比较两个包围盒面积，选择面积较小图像的包围盒宽度 `W`。
3. 统一最小点对距离：
 
```text
minimum_pair_length = W / 2
```
 
4. 距离索引使用 KNN 扩展匹配实际涉及的去重关键点；关键点间距离小于 `minimum_pair_length` 的点对不进入索引。
5. 根据两边距离索引的点对数量选择外层遍历方向：点对数量较少的一侧作为外层，另一侧按距离排序后供二分查找。该优化只改变查找方向，不改变最终变换方向。
 
### 3. 候选点对选择
 
对于外层中的一个点对距离 `d`：
 
1. 在另一图像的有序距离索引中二分查找区间：
 
```text
[d - 3 px, d + 3 px]
```
 
2. 区间内按距离差 `|candidate_distance - d|` 从小到大选择候选。
3. 每个外层点对最多检查 `64` 个候选；区间内不足 `64` 个时只检查实际数量。
4. 对每个候选检查正向或反向的两条 KNN 扩展匹配关系。即使外层是 target，后续仍统一得到 `source -> target` 的两条匹配。
 
### 4. 点对变换投票
 
给定两条扩展匹配：
 
```text
S1 -> T1
S2 -> T2
```
 
1. 计算 source 连线 `S1S2` 和 target 连线 `T1T2` 的方向。
2. 相减并归一化到 `[-180°, 180°)`：
 
```text
angle = direction(T1T2) - direction(S1S2)
```
 
3. 使用该点对自己的 `angle` 构造旋转矩阵 `R`，在图像左上角坐标系计算平移：
 
```text
t = target - R * source
```
 
4. 用两条匹配分别计算平移；若两条匹配的 `tx` 或 `ty` 相差超过 `10 px`，丢弃该点对投票。
 
### 5. 三维离散分箱
 
每个有效点对投票得到 `(angle, tx, ty)` 后直接量化：
 
- `angle`：5° 一个箱，以 0°、±5°、±10° 为箱中心。`[-2.5°, 2.5°)` 属于 0° 箱；`[-180°, -177.5°)` 与 `[177.5°, 180°)` 属于同一个 -180° 箱。
- `tx_bin = floor(tx / 10)`。
- `ty_bin = floor(ty / 10)`。
 
只有 `(angle_bin, tx_bin, ty_bin)` 三个值完全相同的投票进入同一个簇，不使用固定种子角度或种子位移比较，因此不依赖投票处理顺序。

## 灰度密度聚类代替10层暗部提取

| 阶段 | 用例数 | 平均耗时（ms） | 最小耗时（ms） | 最大耗时（ms） |
| --- | ---: | ---: | ---: | ---: |
| FAST | 50 | 71.84 | 18.20 | 189.61 |
| MULTILAYER | 80 | 1624.97 | 154.55 | 14243.88 |

multilayer层的耗时远高于fast层，使用固定10层灰度层的提取有太多重合检测和计算，部分用例可能只需要两三层就够了，因此尝试使用灰度密度聚类作为优化方案。

1. 预处理灰度图：分别对 source、target 进行预处理，并在后续直方图统计中忽略灰度值为 `0` 的背景像素。两张图始终独立处理。

2. 统计灰度直方图：分别统计 source、target 在 `0..255` 范围内每个灰度值对应的非零像素数量，得到两条独立的灰度计数曲线。

3. 寻找候选峰值：在每张图自己的计数曲线上寻找局部峰值。灰度 `g` 只有在计数不小于相邻灰度计数且计数大于 `0` 时才作为候选峰；相邻候选峰之间计数最低的位置作为两峰之间的谷点，最左、最右峰的外侧边界取该图非零灰度范围的端点。

4. 合并相近峰：先将连续的平坦峰顶合并为一个候选峰，平台中部作为候选位置。随后每轮从尚未归组的候选峰中选择最高峰作为锚点，并向左右查找距离小于 `15` 个灰度级、峰高不低于锚点峰高 `10%` 的候选峰。查找不会因为中间某个峰高度不足而立即停止；如果范围内更远的峰满足条件，则更远峰与中间峰一并归入当前峰组。合并后只保留锚点作为代表，扩大该组灰度区间并重新统计面积，不修改原始直方图峰高。

5. 生成峰值区间：每个合并后的可靠峰对应一个灰度区间 `[left_gray, right_gray]`，区间边界取相邻可靠峰之间的谷点；区间 `area` 统计原始预处理图中落在该区间且灰度大于 `0` 的像素数量。

6. 按可靠峰数量选择图层模式：source、target 分别独立判断。少于 `2` 个可靠峰时使用固定十层；恰好 `2` 个可靠峰时使用 2 个密度区间；恰好 `3` 个可靠峰时使用 3 个密度区间；大于等于 `4` 个可靠峰时按 `area` 从大到小选择 top3 区间。

7. 判断 top3 覆盖率：top3 覆盖率为三个区间 `area` 之和除以该图预处理灰度图的非零像素数量。覆盖率达到 `95%` 才使用 top3；低于 `95%` 时回退固定十层。因此，大于等于 `4` 个可靠峰并不代表一定使用密度层。

8. 生成密度层或固定十层：密度层使用各自的 `[left_gray, right_gray]`（含边界）提取非零像素，再单独归一化。固定十层的逻辑阈值为 `[255、229、204、178、153、127、102、76、51、25]`；其中 `255` 原图层直接复用 FAST 阶段的关键点和描述子，实际新增检测九个暗部层（`229、204、178、153、127、102、76、51、25`）。
